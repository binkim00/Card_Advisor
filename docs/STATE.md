## 확정 결정


- CODEF 연결은 사용자/환경/프로젝트/기관별 관리. 외부 요청 전 작업 기록 커밋, 같은 키/본문은 재전송 없이 조회. UNKNOWN은 자동 재시도/로컬 삭제 금지. Connected ID는 AES-GCM 사용자/연결 귀속 암호화, 공급자 해제 성공 후 제거.

- Spring Boot3.5.16/PostgreSQL17.6/Kotlin2.1.20/Compose/AGP8.10.1/Gradle8.14.3, JDK21로 Java17 대상 빌드.
