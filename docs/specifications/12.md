**상태: 구현 전 설계 제안 v1.0.** 수치 목표·기술 선택은 제안값이며 실측 또는 외부 승인 결과가 아니다.
## 확정·제안·미정
**확정:** 사용자 혼자 개발. 관심 대상 네이버 쇼핑·무신사. 기존 쇼핑몰에서 사용자가 직접 결제.<br>**제안:** 네이버 먼저/무신사 다음, 카드3종, Kotlin+Spring Boot+PostgreSQL, 주18~20시간의10~11주 계획.<br>**미정:** 실제 주당 시간, 카드 상품, 기기·주문 경로, 최종 스택·로그인/AI 공급자, CODEF 이용 조건, 운영비 한도.
문서에 일정과 역할이 있다고 확정 약속으로 해석하지 않는다. 모든 개발 작업의 담당은 ‘본인’이며 작업 상태는 계획이다.

## 선행 조건과 중단·축소 기준
- W03 이용 조건 미확인: 실제 연결 W11/W12는 시작하지 않고 합성 응답·수동 M0 진행.
- W02 네이버 금액 미노출: W14를 무신사로 교체. 둘 다 실패하면 자동감지 미완료로 남기고 수동 MVP만 시연.
- 실제 카드의 핵심 조건을 해석 못함: 해당 카드를 미지원/조건부로 두고 확인 가능한 상품부터 사용.
- AI 수치 검증 실패: AI 설명 비활성, 템플릿으로 제공.
- 외부 답변·심사 지연: 진행 중인 상태를 기록하며 코드 완성을 승인으로 보고하지 않는다.

## CODEF에 확인할 내용 — 문의 초안, 미발송
개인 1인이 본인 명의 카드·계좌로 결제 전 추천 앱을 개발하려고 한다. 데모에서 이 사용 목적이 허용되는지, 기간/일·월 쿼터/집계 단위/실패 요청 차감, 지원 기관·인증 방식, 카드 실적·한도·승인/매입/취소 필드, 사용자가 누르는 갱신과 예약 조회 허용, 인증정보 보관 및 연결 해제 방법, 이후 타인 테스트·공개 배포 조건을 확인한다.
