## 발견·수정 및 미확정 사항
- 수동 고정비와 반복 예약액을 더하면 중복 차감되는 경로를 월별 계산 기준 선택으로 방지했다.
- 다음 월 고정비 화면에서 예산 설정으로 이동할 때 현재 월로 돌아갈 수 있던 연결을 선택 월 전달 방식으로 수정했다.
- 최초 실행 `6c156a4b-a73c-4fe2-8ad4-be19f550aaf7`에서 Activity 종료 중 `ArrayIndexOutOfBoundsException / SlotWriter.moveSlotGapTo`가 발생했다. 최초 원인 예외가 종료 오류에 가려져 정확한 원인은 미확정이다. 당시 합성 계정에 일정/거래가 저장되지 않았음을 확인하고 그 계정1개만 정리했다.
- 테스트의 동작별 기록과 최초 예외 파일, 실패 시 증거 회수를 보강했다. 이후2회 전체 흐름이 통과했다. 추적 추가/재실행 성공을 제품 오류의 원인 수정으로 주장하지 않는다. 집중 재현을 STATE 다음 행동으로 남겼다.

## 실행 방법
1. 기존 PostgreSQL과 API를 실행해 `/v1/health`가 UP인지 확인한다.
2. emulator-5554 실행 후 `./scripts/android.ps1 fixed-test`: 빌드/설치→실제 UI→API→DB 확인→성공한 합성 계정 정리.
3. API 경계만 검증: `python scripts/fixed_smoke.py`.
4. 직접 사용: 설정 → 반복 고정비 관리 → 일정 추가 → 월별 계산 기준 선택 → 해당 월 가계부 거래 연결. 추가 지출이 없는데 실제액이 예상보다 적다면 예상액을 수정한다. 연결 해제는 거래를 지우지 않는다.

다른 월 청구/납부 금액 배분, 한 거래의 일부 금액 배분, 자동 매칭 후보, 알림은 이번 구현 범위에 포함하지 않았다. 실제 카드 약관/실금융과는 별개다.
