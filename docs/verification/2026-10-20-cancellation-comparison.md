# 취소·원래 결제 비교 화면

- 취소를 선택하면 일반 거래 목록 대신 확인 화면을 보여준다. 취소 요약과 각 원래 결제 후보에 가맹점/카드명/카드 끝자리/날짜/금액 표시. 후보 선택 후 선택한 결제와 환불 기록 금액을 다시 표시하며 명시적 확인 버튼으로만 저장한다. 돌아가기는 미저장.
- 같은 가맹점/같은 금액을 비교 힌트로 표시하지만 자동 선택하지 않는다. 같은 카드·취소일 이전·잔여 금액 충분·누적 취소 방식과 충돌 없는 결제만 제시. 표시 이름은 동일성을 확정하는 근거로 쓰지 않는다.
- API도 미래 결제/초과 환불/기존 누적 취소 방식을 연결 전에 거절하여 실패 시 연결값이 남지 않도록 했다. 기존 소유권/버전/원장/동일 카드 검증 유지.
- PostgreSQL 기존17개 통과 및 신규 미래·초과 연결 미저장1개 통과. 에뮬레이터→합성API/공급자→실 PostgreSQL1개 흐름 통과: 미선택 저장 차단, 취소요약/선택결제 비교 존재, 명시적 연결·재조회·부분취소·중복환불 방지. 합성 계정 정리.
- 실제 데이터는 이름·금액 원문 없이 후보 건수만 확인: 취소1건/후보15건/같은 가맹점0/같은 금액0. 원래 결제가 무엇인지는 미확정. 이전 달 조회 또는 카드사 원내역과 사용자 대조 필요. 실제 취소 연결·환불 기록은 수행하지 않았다.
