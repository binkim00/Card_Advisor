- 고정 기본값 표시/저장 직전 최신 버전 취득으로 인한 덮어쓰기 가능성 → 저장값·조회 당시 버전으로 교체.
- 쇼핑 한도만 보내 다른 분류를 잃는 경로 → 조회된 전체 카테고리 맵 보존 및 편집.

- 검증 도구의 중복 BOM, 깊은 JSON 증거 절삭, 재조회 중 아직 비활성인 필드 입력 타이밍도 수정 후 최종 재실행했다.
- 기존 V1~V7 마이그레이션 변경 없이 동작한다.

## 재현 방법
1. PostgreSQL과 `scripts/start-backend.ps1`로 API를 준비하고 `/v1/health`의 UP 확인. 시작 명령 직후에는 아직 준비 전일 수 있다.
2. emulator-5554 실행 후 `./scripts/android.ps1 budget-test`: 앱/테스트 빌드·설치→포트 연결→화면 조작→DB 대조→해당 합성 계정 정리.
3. API만 검증: `python scripts/budget_smoke.py`. 실패한 Android 실행은 실행 ID로 `.run`에서 진단한다.
4. 직접 사용: 설정 → 월별 예산 수정 → 월 선택 후 저장값 불러오기 → 전체/미반영 고정비/분류 한도 입력 → 월 예산 저장. 충돌하면 최신 값 조회 후 다시 수정한다.
