# 2026-10-20 Android 주요 화면 디자인 개편

사용자 요청: 기능을 유지하면서 실제 서비스처럼 화면을 정리한다.

- 홈: 남은 예산을 파란 그라데이션 요약으로 표시, 카드 비교 진입을 주요 동작으로 분리, 실제 조회된 보유 카드만 표시. 등록 여부와 무관한 공식 상품 갤러리를 홈에서 제거했다.
- 내 카드: 공식 썸네일과 이번 혜택 자격, 다음 달용 실적, 혜택 잔여 한도, 부족액을 구분. 미확인을 0으로 바꾸지 않는다.
- 설정: 카드·금융, 소비 관리, 앱 설정별 동작 목록. 가상 데이터 생성은 접은 별도 영역에 둔다.
- 공통: 연회색 배경, 흰 패널, 20~28dp 모서리, 글자/간격 계층. 추천 결과/가계부/상품 등록에도 적용. 세부 화면 이름을 구분하고 로그아웃은 설정에서 제공한다.
- 홈(7)이 설정의 관리 화면 범위(3..12)에 포함돼 두 메뉴가 동시에 선택되던 오류를 수정했다.
- ApiClient, 세션 저장소, API/DB/계산 코드 변경 없음. 기존 콜백/입력/요청은 유지한다.

## 검증

- 최종 debug 및 androidTest APK 빌드 통과: `.run/service-design-build.log`.
- 합성 Compose 검사3개 통과: 홈·선택 상태·탐색/로딩, 미확인 예산, 실제 추천/가계부 컴포넌트의 합성 결과·부분 취소 표시. `.run/service-design-ui.log`.
- 합성 화면 PNG를 직접 확인했다. `.run/service-design-preview/design-preview/`의 home-top, home-cards, recommendation, ledger. 실제 금융 정보가 없는 격리 구성이다. 추천/가계부 이미지는 해당 표시 컴포넌트 검사이며 전체 API 화면 조작의 증거와 구분한다.
- AndroidSyncPostgresTest 에뮬레이터→Spring API→합성 공급자→PostgreSQL 전체흐름 통과. 연결/최초 동기화/거래 대조/카드 상품 매핑/취소/응답유실 복구/Activity 재시작·세션 폐기, 테스트계정 삭제. `.run/service-design-flow.log`, `.run/service-design-flow.json`.
- 첫 회귀 실행은 마지막 로그인 화면의 이전 문구 기대값으로 실패했다. 기능 단계는 진행됐고, 변경 문구로 검사 기대값을 수정한 후 전체 흐름을 재실행해 통과했다.
- SM-F741N에 `install -r` 성공, USB18080 연결과 일반 앱 실행. 개인 데이터·암호화 세션 삭제 없음. 이번 변경으로 실기기 전체 금융 흐름을 재실행하지 않았으며 실기기 설치와 에뮬레이터 기능 검증을 구분한다.

## 범위

주요 화면과 공통 디자인 변경이다. 금융/고정비 등 긴 입력 화면의 세부 정보 구조는 추가 개선 대상이며 모든 화면의 최종 디자인 완료 또는 전체 서비스 완성을 의미하지 않는다. 실제 CODEF 호출/개인 거래 변경/배포 없음.
