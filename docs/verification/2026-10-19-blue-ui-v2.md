# 승인 목업 구조 재적용 — 2026-10-19

기존 구현은 색상·카드 테두리 변경에 그쳤고 큰 설명 패널과 항상 열린 폼이 승인 목업의 구성을 가렸다. 홈/추천/가계부의 정보 배치와 밀도를 다시 구성했다.

- 홈: 흰 배경, 작은 헤더, 연한 파란 예산 패널, 카드 비교 CTA, 공식 상품 이미지 3개를 가로 목록으로 배치. 테스트 실적은 펼침 영역으로 이동.
- 추천: 결제 요약→모드 선택→가로형 추천 결과→구매 후 예산. 세 금액 입력은 '결제 정보 수정'으로 열며 계산 기준도 펼침 처리.
- 가계부: 월 지출·잔여 예산, 실제 카테고리 필터, 거래 목록. 수동 입력, 거래 카드 연결/분류/취소, 예산·실적 상세는 선택해서 연다. 거래 출처는 MANUAL 여부로 구분하며 가맹점명은 만들지 않는다.
- 공식 카드 이미지는 상품 안내다. 가상 A/B 계산 결과에 실제 카드 이미지를 붙이지 않는다. 다른 채팅이 추가한 FinanceEditor 갱신 콜백·보류 금융 거래 안내·최신 금융 파일을 사본에 병합해 보존했다.
- API 요청식 14개 보존. busyState 직접 관찰 유지. 기존 관리 화면 API·계산 엔진은 변경하지 않았다.

## 경계와 충돌 보존

실금융 연결, 실제 카드 혜택 검수, 실제 쇼핑몰 감지, 공개 배포/스토어 승인은 이번 결과에 포함하지 않는다.
