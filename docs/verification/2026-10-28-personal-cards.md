# 사용자별 카드 화면 — 2026-10-28

공통 상품 카탈로그가 보유 카드처럼 보이는 문제를 수정했다. 새 계정에 가상 카드나 상품을 자동 등록하지 않으며, 기존 사용자 데이터는 삭제하지 않았다. 추천 기본 모드는 내 실제 카드다. 홈에서 가상 카드를 제외하고 첫 카드 등록 버튼을 제공한다. 가상 시연 준비는 설정의 접힌 영역에 유지한다.

내 카드 화면은 사용자별 `/v1/cards` 응답의 등록 카드를 먼저 표시하고, 공식 상품 카탈로그는 `카드 직접 추가하기`를 펼칠 때만 보인다. 금융 연결 저장 여부도 구분한다. `카드사 연결하기`는 기존 금융 연결/이용내역 조회 화면으로 연결한다. 특정 상품을 사용자 보유 카드로 추정하지 않는다. 등록 가능 상품과 혜택 규칙 지원 범위는 기존 카탈로그 범위이며 모든 카드 상품 지원을 뜻하지 않는다.

## 불러오기 범위
`CodefClient.cards`의 `/v1/kr/card/p/account/card-list` 어댑터/계약 검사는 이미 존재하지만, 사용자별 보유 카드 조회·검증·저장·상품 확인 화면의 전체 흐름은 아직 미구현이다. 현재 금융 동기화는 이용내역에 등장한 카드를 식별·사용자 상품과 명시적으로 연결하는 범위다. 카드사 인증·동의·서비스 설정/이용 권한이 필요하며, 배포 서버 금융 설정은 계속 공백이다. 이번 작업으로 실금융 호출이나 자동 등록을 켜지 않았다. [CODEF 공식 SDK의 보유 카드 조회 설명](https://github.com/codef-io/easycodef-node/blob/master/README.md).
