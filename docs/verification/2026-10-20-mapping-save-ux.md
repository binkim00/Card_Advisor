# 2026-10-20 상품 등록·금융 카드 연결 저장 동선 수정

## 확인한 원인과 한계
- 실제 계정 감사에서 상품은 등록돼 있으나 금융 카드 상품 관계는0건이었다. 이 상태만으로 사용자가 이전에 어떤 버튼을 눌렀는지, 과거 요청이 실패했는지 단정할 수 없다. 사용자가 연결했다고 한 말을 부정하거나 서버 유실로 단정하지 않는다.
- 기존 ‘내 카드에 추가/등록됨’은 cards만 저장하며 financial_card_mappings를 저장하지 않았다. 상품 등록 화면에는 이 구분과 연결 진입이 없었다.
- 금융 카드 화면의 상품 선택은 임시 상태이며 별도 확인 체크/저장까지 필요했지만 선택 상태 표시가 약하고 긴 목록 아래 저장 버튼이 있었다. 선택 화면에서 상품 등록 시 load()가 선택 그룹까지 닫아 다시 진입해야 했다.
- 기존 백엔드의 명시적 사용자확인/사용자격리/버전검사/DB저장 자체는 API·PG와 에뮬레이터 검증에서 동작했다. 이번 수정의 핵심은 불명확한 상태·누락되기 쉬운 저장 동선이다.

## 수정
- CardProductsEditor: 상품 등록 완료와 금융 카드 미연결/저장됨/조회실패를 구분. 연결 관계 GET을 읽어 등록상품별 실제 저장 건수 표시. ‘금융 카드 연결하기’로 해당 카드사 화면에 직접 진입.
- FinancialCardMappingEditor: 같은 카드 확인과 선택한 연결 저장 버튼을 고정한 대화상자. 선택 상품 강조, 선택/확인 전 저장 비활성. 새 상품 등록 후 대화상자 유지, 다시 화면을 찾을 필요 없음. 실제 카드 선택은 사용자 직접 수행.
- PUT응답을 받은 뒤 GET으로 선택한 sourceKey/cardId/version 일치를 검증한 후에만 저장·재조회 완료 안내. 후속 카드현황 갱신 실패를 저장 실패로 오인하지 않음.
- 충돌/결과불명확은 대화상자 안에서 오류와 ‘서버 저장 상태 다시 확인’ 제공. 자동 재전송 없이 최신 GET으로 복구. 해제/버전/사용자확인 조건 유지.
- 실제 금융 거래 실적·혜택 자동 계산이 미완성임을 명시. 상품 연결 저장을 계산 완료로 표시하지 않음. 계산/거래금액/취소/DB스키마/인증정보 변경 없음.

## 검증
- 최종 debug/검사APK 빌드 `.run/mapping-save-build.log`.
- SM-F741N→API→loopback합성공급자→PostgreSQL: 상품등록만 미연결 표시, 직접선택/확인전 저장차단, 저장/GET재확인/새로고침/Activity재시작 후 연결저장 상태/버전1 확인. 기존 수동구매/부분·전체취소/금융금액표시/예산·실적/미검수null 유지도 통과. `.run/mapping-save-physical.log`, `mapping-save-physical.json`.
- 개인로그인 암호문 불변/기존DB불변/합성계정삭제. 실기기 첫 대기는 잠금/최초Root생성전 조회 조건을 보완하고, 저장 후 후속 갱신 중 비활성 버튼을 누르던 검사 대기를 수정한 뒤 최종전체경로 통과.
- 에뮬레이터의 선택창내 상품등록 유지/충돌/복구/해제/재연결은 `.run/mapping-save-regression.log`, `mapping-save-regression.json`으로 별도 확인. 실제 CODEF 호출0.
- 수정 APK 실기기 설치 및 일반 개인앱 복원 완료. 실제 계정의 금융 카드와 상품은 자동 선택/저장하지 않았다. 사용자가 직접 저장한 뒤 실제 GET/DB 관계를 최종 확인해야 한다.

## 실제 계정 직접 저장 확인 완료
- 사용자가 직접 선택·저장했다고 응답한 뒤 실제 PostgreSQL 집계에서 금융 카드↔상품 연결1건을 확인했다. 해당 상품 관계가 금융 원장187건에 표시되며 원장187/고유187/현재월32/표시누락0/미연결취소1 유지.
- 같은 개인 저장로그인과 정상API로 실기기 비공개 GET감사. 상품등록 화면 ‘금융 카드 연결 저장됨’, 연결 화면의 선택상품/저장버전, 새로고침 및 Activity재시작 후 같은관계 유지 확인. 상품을 재선택/재저장하지 않았다.
- 검사 전후DB10표 불변/개인로그인유지/일반앱복귀. 원문·스크린샷·인증정보 출력없음. 외부CODEF 재조회없음.
- 근거 .run/mapping-real-saved-audit.json, .run/ledger-real-metadata.json, .run/mapping-real-audit-build.log 및 PrivateLedgerAuditTest.savedMappingReadOnly/scripts/verify-real-mapping-private.ps1.
- 상품 연결 저장은 실제계정에서도 완료됐다. 실금융 거래의 실적 인정·제외·취소귀속 및 혜택한도 계산의 미완료 경계는 유지한다.
