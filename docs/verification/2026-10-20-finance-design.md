# 2026-10-20 금융 연결·이용내역 디자인

## 구현
- FinancePresentation.kt: 카드사 이름/연결 상태, 전체·가계부 기록·확인 필요 건수, 거래의 가맹점·날짜·금액·카드 상품/카드사 이름·끝자리 표시를 공통 컴포넌트로 구성.
- FinanceEditor: 기존 흰 패널/파란 강조 디자인 적용. 기관 코드 대신 KB국민카드/하나카드를 우선 표기하며 알 수 없는 기관은 원래 코드를 남김. 기간별 이용내역 버튼을 주요 동작으로 강조. 재인증/해제/실패 수정·삭제/결과 조회/상품 연결의 조건과 콜백 유지.
- FinanceSyncEditor: 저장 거래와 건수를 우선 보여주고 날짜 입력은 ‘다른 기간 이용내역 불러오기’로 펼침. 전체 거래 목록은 기존처럼 조회 요청 기간 밖 저장 내역도 포함하며 날짜 패널에 명시.
- 연결한 상품명이 있으면 우선 사용하고 공급자 표기가 다르면 함께 표시. 없는 정보를 추정하지 않으며 끝자리3/4자리만 표시.
- 부분 취소는 원래 결제액/취소액/취소 후 금액, 전체 취소는 별도 상태. 원거래 미확인 취소는 원래 결제 확인 필요로 표시하고 가계부 반영 전임을 설명. 기존 직접 선택·최종 확인 전 자동 연결 없음.
- 수동 거래 중복 대조, 이전 달 불러오기/취소 후보 비교, 계산 제외, 버전 충돌과 UNKNOWN/진행중 요청의 전송 차단 유지.
- 미확인 금액은 ‘미확인’, 합성 응답은 테스트 내역임을 표시. 실제 카드 실적·혜택 미검수 경계 유지.
- API/계산/DB/세션 제품코드 변경 없음. 금융 화면 FLAG_SECURE와 입력 종료시 인증정보 제거 유지.
