## 발견과 수정
기존 나가기 버튼은 서버 로그아웃이 성공해야 로컬 세션을 비웠다. 이미 만료된 세션의401을 정상적인 로컬 로그아웃으로 처리하도록 수정했고, 위 실제 DB 만료 검사로 확인했다. 로그아웃 때 선택 탭도 초기화한다.

최초 자동 검사1회는 비밀번호 필드의 표시 라벨까지 포함하는 텍스트 비교/조회 완료 대기 지점에서 멈췄다(`.run/android-finance-first.json`). 입력값 의미 속성을 직접 확인하고 버튼 활성까지 대기하도록 테스트를 보완했다. 그 뒤 전체 연결 흐름이 통과했다(`.run/android-finance-lifecycle-pass.json`). 이를 별도의 제품 종료 오류 수정으로 주장하지 않는다.

## 실행
프로젝트에서 `./scripts/android-finance-test.ps1` 실행. 기존 PostgreSQL과 emulator-5554 필요. 다른 승인된 테스트 기기는 `-Device <adb 식별자>`. 스크립트가 APK 빌드/설치, 테스트용 Spring 서버, 합성 공급자, 실제 DB 검증과 합성 계정 정리를 수행한다. 테스트 제어 경로는 backend/src/test에만 있고 배포 JAR에 포함하지 않는다. 화면/HTTP 원문/인증 입력은 결과 파일에 저장하지 않고 실패한 테스트 소스 행만 남긴다.

앱에서는 로그인 → 설정 → 금융 연결 관리. 평소 로컬 서버는 공급자 비활성 상태라 조회만 허용한다. 실제 인증정보를 넣어 시연하지 않는다. 합성 성공은 자동 검사의 임시 서버에서만 나온다.

## 미검증·남은 범위
실제 금융기관 연결, 물리 휴대폰, OTP/인증서 이어하기, UNKNOWN 공식 대조/복구, 기관별 거래 정규화/동기화, 공개 배포·스토어 승인은 미완료다. 로컬 금융 조회는 저장 상태 조회이며 CODEF의 현재 연결 상태를 다시 대조한 것이 아니다. 기관 코드는 공식 확인 후 사용하며 실제 KB/하나 코드·지원 방식을 추측하지 않았다. 일반 오프라인/잘못된 응답 보류는 구현했으나 이번 끝까지 연결한 검사는 HTTP500·UNKNOWN·401·409 경로다.

## 일반 로컬 서버 반영

DB는 중단하거나 초기화하지 않았다. 근거 .run/android-finance-runtime.json 및 android-finance-package-final.log.
