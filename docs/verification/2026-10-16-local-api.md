## 재현과 현재 실행 상태
현재 PostgreSQL과 백엔드는 실행 상태로 남겨 두었습니다. 이번 검증에서 백엔드 PID는 46568이며 최신 값은 .run/backend.pid를 확인합니다.

프로젝트 폴더에서:
1. Docker Desktop이 실행된 상태에서 `docker compose up -d --wait db`.
2. 서버가 꺼져 있으면 `powershell -ExecutionPolicy Bypass -File scripts/start-backend.ps1`. 실행 중인 서버를 중복 시작하지 않습니다.
3. `python scripts/api_smoke.py`로 합성 계정을 생성하고 실제 DB/API 검사를 재현합니다. 이 검사는 종료 시 생성한 계정을 삭제합니다.
4. `http://127.0.0.1:18080/v1/health`에서 현재 서버 응답을 확인할 수 있습니다.

.env의 DB 비밀값은 그대로 로컬에 보관하며 채팅에 복사할 필요가 없습니다.
