## 구현 완료
가계부의 각 거래에 '분류·예산 포함 수정' 화면을 연결했다. 카테고리 선택과 예산 포함/제외 저장, 최신 거래 재조회, 충돌 시 초안 보존, 명시적 최신 값 초기화를 지원한다. 분류 변경은 카드 승인/환불액·실적·혜택 규칙을 변경하지 않는다. 가계부는 전체/카테고리별 순지출·잔여 예산을 다시 조회하고, 이전 추천을 지워 다시 계산하게 한다.

- API: GET /v1/transactions/{id}, PUT/PATCH /v1/transactions/{id}/classification, GET /v1/budgets/{month}/summary.
- 분류는 category/included/version을 모두 받는다. 원문 PATCH 호환 별칭을 제공하고 Android는 전체 분류 상태 PUT을 사용한다.
- V7은 분류 전용 버전·수정시각·최초 분류/포함 여부를 보존한다. 기존 구매 재전송이 수정된 분류와 충돌하던 문제를 최초값 비교로 수정했다.
- 이전 버전은409, 누락/잘못된 입력은422, 다른 사용자 거래는404. 동일 버전/동일 값 저장은 상태·추천 버전을 불필요하게 변경하지 않는다.
- 예산 미설정 카테고리는null/미설정으로 표시한다. 예산 재조회 중 또는 실패하면 이전 예산 요약을 최신 값처럼 남기지 않는다.

## 실행 방법
백엔드/PostgreSQL/에뮬레이터를 실행한 뒤 프로젝트 루트에서 `./scripts/android.ps1 classification-test`를 실행한다. 앱·검사 APK 빌드와 화면/API/DB 검증·계정 정리가 포함된다. API만 확인하려면 `python scripts/classification_smoke.py`. 기존 흐름 회귀는 `./scripts/android.ps1 ui-test`.

앱에서는 가입/로그인 → 가상 데이터 준비 → 가계부의 사용 카드 선택/구매 기록 → 거래의 '분류·예산 포함 수정'. 금융기관의 업종이나 실제 결제 상태를 바꾸는 기능이 아니다.
