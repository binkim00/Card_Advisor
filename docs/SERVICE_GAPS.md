# 실제 서비스의 주요 미완료 경계

전체 서비스는 미완료다. 화면·합성 검증과 실제 금융 자동 계산/배포를 구분한다. 일정 추정은 두지 않는다.

| 기능 | 현재 구현 | 남은 구현·검증 | 완료 판정 |
|---|---|---|---|
| 금융 카드↔상품 연결 | 사용자확인 PUT/GET·버전·격리, 등록/연결 구분 및 고정 저장 버튼 | 실제계정 직접저장/GET/새로고침/재시작까지 확인 완료. 실거래 계산은 다음 항목과 별개 | 직접 선택→저장→GET/재시작 유지, 거래불변 |
| 실제 금융 거래의 다음 달 실적 | V20 인정/제외/미확인·증거버전·취소별 접수일 검토, KB 접수월 차감 및 월별 커버리지·합산. PG28/계산11/실기기→API→DB 통과 | 실제 사용자의 명시 확인/공식 월실적 대조, Hana GO 환불귀속 검증 | 현재자격 분리·미확인≠0·중복배제·공식명세 대조 |
| 실제 금융 혜택 사용·잔여한도 | 제한된 수동 결제 예상과 가상 거래별 재계산 | 실제 거래별 업종/결제채널/취소 정산과 혜택 적용 증거, 상품별 월·세부한도 차감/복원. 공식조회/자체추정 분리 | 중복차감없음·부분취소경계·한도초과·룰버전 테스트와 공식명세 대조 |
| 이번 결제 혜택 자격 | 별도 월별 입력·출처/기준기간, 실적 증가로 현재자격을 승격하지 않음 | 공식 데이터 지원 범위 확인과 전월 인정액 대조. 단순 당월 누적과 혼합 금지 | 월경계·재조회·미확인·출처 정합 |
| 금융 연결 운영 | 실제 KB DEMO 연결/거래조회, 합성 재인증/해제/UNKNOWN 보호 | 추가인증 이어하기·UNKNOWN 공급자 대조·하나 실기관 검증, 운영계약/호출조건 | 기관별 실제 성공/실패·재인증·해제 증거 |
| 쇼핑몰 감지 | 앱별 어댑터/수동확인/변경무효화 | 네이버플러스 스토어·무신사 실제 주문경로/버전별 검증 | 실제 기기에서 읽은 값 사용자확인, 민감화면 차단 |
| 운영·배포 | 로컬 인증·DB·앱·최소 진단, AI실패시 핵심계산유지 | 이메일소유/비밀번호복구·운영HTTPS/백업복구·릴리스/스토어 검증 | 로컬/배포준비/공개배포/스토어승인을 분리한 근거 |

금융 거래의 실적 검토 저장·합산 구현은 완료했으며 실제 명세 대조와 위 남은 범위는 별도로 유지한다. 상품 연결만으로 모든 거래를 실적 인정하거나 금액과 혜택을 확정하지 않는다. 전체 FR별 추적은 docs/REQUIREMENTS.md를 따른다.


## 2026-10-20 전체 구현 진행 체크포인트 (위 표의 이전 상태를 갱신)
- 실제 금융 혜택: V21에서 KB AUTO 그룹/영역 한도·취소 후 예상 복원, 트래블로그 국내 일반, 검토·월별커버리지·추천 연결까지 구현/합성 실기기 검증 완료. 공식 잔여한도 조회·실제명세 대조, GO/해외/할부·소수점 등 미검증 조건은 계속 보류.
- 계정: V22 이메일 확인·복구와 전체 세션 폐기 구현, 합성 메일 PG4개 통과. 실제 SMTP 발송 서비스는 미정이므로 실제 발송/운영 적용은 미완료.
- 분석: 실제 가맹점 로컬단서 제안과 전월 같은 날짜까지 비교 추가, 사용자 수정 우선·원문 AI미전송. 실제 OpenAI 호출/품질 평가는 미완료.
- 운영: 암호화 로컬 백업/격리DB 복원 검증 완료. 운영 TLS프로필과 release HTTPS 주소 설정 추가. 운영 삭제/다중호스트복구/CI/공개배포/스토어는 미완료.
- 감지: 재시작시 스위치초기화 결함 수정 및 debug 비식별 진단 추가. 실제 지원 앱의 주문서/권한거절·변경무효화 확인은 진행 중.
