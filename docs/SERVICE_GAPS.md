은행 계좌 전체 동기화나 모든 금융/쇼핑 상품 범위로 확대하지 않는다. 현재 지원 범위는 KB/하나 개인카드 승인 연동이며 통장 카드대금 출금을 새 소비로 계산하지 않는다. 미확인 조건은 보류한다. 조회가 공식 method와 공통 이어가기 식별자를 실제 반환한 경우만 지원하는 추가 인증을 표시한다. 기관이 특정 방식을 제공한다고 미리 가정하지 않는다. 계정 생성은 여러 accountList 항목을 포함할 수 있어 조회용 파라미터 배치를 임의로 복제하지 않는다.

공개 배포·스토어 승인·새 실금융 인증·유료 호출은 수행하지 않았다. 기존 계정·로그인·실제 거래·상품 연결과 보류 취소는 유지한다.

계정 생성 추가 인증·트래블GO 취소의 공식 자료 대조, 구현 범위와 필요한 상세 규격은 [CODEF_TRAVELGO_OPEN_QUESTIONS.md](CODEF_TRAVELGO_OPEN_QUESTIONS.md) 참조. 해당 사용자 설정이 부족해서 중단된 것으로 표현하지 않는다.
